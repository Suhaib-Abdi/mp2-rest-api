# MP2 REST API

This project is a FastAPI application that wraps my MP1 data pipeline in a REST API. A client can upload a CSV file (`POST /upload`), which is stored in memory and given an ID. The stored rows can be retrieved with an optional row limit (`GET /datasets/{dataset_id}`), and a dataset can be validated and cleaned by sending a JSON configuration to `POST /datasets/{dataset_id}/process`, which removes invalid values, duplicates, missing values, and optionally outliers using the reusable MP1 modules in `data_pipeline/`. `GET /health` reports the application status and version. Every request is logged with a request ID, status code, and duration by middleware, and the API is tested with pytest. Run it with `python -m uvicorn main:app --reload` and explore it at `/docs`.
